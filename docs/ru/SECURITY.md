# Политика безопасности

[English version](../../SECURITY.md)

## Сообщение об уязвимости

Напишите на [s.bokonyaev@yandex.ru](mailto:s.bokonyaev@yandex.ru) с темой `Ruleblend security`.
Используйте этот приватный канал для уязвимостей, включая непреднамеренную запись вне управляемых
областей, небезопасный импорт архивов или Git и раскрытие секретов либо приватной конфигурации.

Укажите версию и сборку, операционную систему, затронутую операцию, возможные последствия и
минимальное воспроизведение на тестовых файлах. Удалите токены, личные пути, URL приватных репозиториев
и посторонние настройки. Не отправляйте реальную библиотеку и не проверяйте уязвимость на чужой среде.

Не публикуйте детали эксплуатации и чувствительные данные в issue или pull request, пока сообщение
проверяется. Согласуйте раскрытие с владельцем после появления исправления или способа снизить риск.
Владелец оценит сообщение и обсудит дальнейшие действия по почте; сроки ответа и исправления
не гарантируются.

## Поддерживаемые сборки

Во время разработки альфы исправления безопасности направляются в текущую ветку разработки.
Для старых сборок может потребоваться обновление; веток долгосрочной поддержки нет.

Об обычных ошибках сообщайте через шаблон issue. Проверки разработки и гарантии записи файлов
описаны в [CONTRIBUTING](CONTRIBUTING.md).
