## Рекурсивный поиск неуправляемых файлов инструкций

Панель *Found in project* сканирует файлы цели и файлы, доступные через импорты
Claude Code, но не находит инструкции в остальных частях монорепозитория.

- Рекурсивно искать `AGENTS.md` и `CLAUDE.md` с ограничением глубины, пропуская
  генерируемые каталоги и зависимости. Не искать форматы неподдерживаемых агентов.
- Файлы вне `Target.ownedFiles()` разрешать только копировать в библиотеку:
  замена управляемой областью недопустима, поскольку Ruleblend не сможет её обновлять.
- Не менять глобальные цели агентов: у каждого каталога конфигурации один известный файл инструкций.

## Типы элементов помимо правил, MCP-серверов, скиллов и субагентов

Hooks, разрешения `settings.json`, пользовательские промпты Codex, ignore-файлы,
секции `config.toml` кроме `mcp_servers`, плагины, marketplaces и команды
(`.agents/commands`) читаются ассистентами, но не моделируются. Для добавления в
библиотеку каждому типу нужны собственные правила установки и определения локальных изменений.

## Редактирование импортированных скиллов на месте

Развить текущую [модель изменённой копии](ARCHITECTURE.md#git-repository-imports):
один скилл с нетронутой копией `upstream/` рядом с `files/`, трёхстороннее слияние
при обновлении и разрешение конфликтов через Compare.
