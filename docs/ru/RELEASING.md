# Подготовка публичного выпуска

[English version](../RELEASING.md)

Принятые решения для первой альфы.
Этот документ фиксирует целевое устройство выпуска, а не факт публикации.

## Лицензия

- Собственный код и графика используют [PolyForm Noncommercial 1.0.0](../../LICENSE).
- Коммерческие условия оформляются отдельно; контакт публикуется в README.
- Проект не позиционируется как OSI open source.
- `NOTICE` и `THIRD-PARTY.md` содержат атрибуцию по проверенным лицензиям поставляемых
  зависимостей и ресурсов. Предварительный список из плана не заменяет проверку состава сборки.

## Репозиторий и история

- Публичная история начинается в отдельном репозитории с одного коммита `Public alpha` из
  проверенного экспорта. Это отделяет публикуемый исходный код от приватной истории и рабочих материалов.
- Приватный репозиторий хранит полную историю и никогда не добавляется remote'ом публичного.
  Уже опубликованные в приватном remote коммиты не переписываются.
- Автор публичных коммитов — GitHub noreply-адрес; опубликованный контактный адрес остаётся.
- Публичный CHANGELOG начинается с пустого `[Unreleased]`; прежние записи остаются приватными.
- После публикации сообщения новых коммитов — на английском; до неё действует текущее правило проекта.

## Состав публичного дерева

- Рабочие `docs/PLAN.md` и `docs/ru/PLAN.md` и вспомогательные `tools/run_phases.sh`, `tools/split_kt.py`
  остаются приватными. Поставляемые ресурсы приложения входят в публичную сборку.
- Оставшиеся графические материалы `docs/art/` остаются приватными;
  целевое место — игнорируемый `private/`.
- Корневые `AGENTS.md`, `CLAUDE.md` и локальные настройки инструментов исключаются из
  публичного дерева, но сохраняются локально. В ignore учитываются `/AGENTS.md`, `/CLAUDE.md`,
  `private/`, `.claude/`, `.vscode/`, `*.log`, `.swiftpm/`, `.build/`.
- Ссылки публичных документов должны вести только на публикуемые файлы: при подготовке
  дерева ссылки на приватный план и графические материалы заменяются публичными документами или удаляются.

### Экспорт и аудит

Использовать закоммиченное дерево через `git archive`, а не копию рабочей папки или её `.git`.
Исключения экспорта заданы в `.gitattributes`; `.gitignore` не исключает уже отслеживаемые файлы.
Приватные оригиналы остаются в этом репозитории. Создать `build/`, если его ещё нет, затем выполнить:

```sh
git archive --format=tar --output=build/public-alpha.tar HEAD
python -B tools/check_public_tree.py build/public-alpha.tar
```

Аудит проверяет исключённые пути, локальные назначения Markdown-ссылок, распространённые
сигнатуры секретов и абсолютные пути домашних каталогов в UTF-8-тексте. Находки выводятся
с расположением, без совпавших значений. Синтетические пути в тестах нужно проверить явно;
чистый результат не гарантирует обнаружение всех секретов. Перед публикацией повторить
экспорт и аудит итогового коммита.
После просмотра каждого совпавшего значения повторить запуск с `--reviewed <digest>`, указав
напечатанный digest. Это принимает находки секретов/путей только для точных байтов архива;
ошибки структуры принять нельзя. Изменение архива требует новой проверки.

## Артефакты альфы

- macOS DMG и Windows MSI; подпись пакетов в первую альфу не входит.
- Включать лицензионные тексты в оба пакета, а рядом с установщиками предоставлять полный
  архив соответствующих исходников Java с контрольной суммой поставщика. Сохранять notices
  и метаданные runtime для сопоставления пакета с исходниками; см. [THIRD-PARTY](../../THIRD-PARTY.md).
- Workflow публикации по тегу остаётся TODO. Автоматизация публикации не включена.
  Целевой тег — `v<ver>-alpha.1`; он должен совпадать с `appVersion`.
- Исходники Java выбираются по метаданным упакованной Temurin 21, проверяются по SHA-256
  поставщика и собираются с исходными notices и метаданными runtime. JSON происхождения
  каждой платформы связывает установщик и ZIP исходников; `SHA256SUMS` охватывает все артефакты.
- Установка неподписанных пакетов — в [README](../../README.ru.md#установка-неподписанной-альфы).
- Источник версии — `appVersion` / `appBuild` в `app/build.gradle.kts`;
  `appVersion` меняется только по явному указанию Сергея.
- Устройство Windows-установки и сохранность пользовательских данных — в
  [ARCHITECTURE](ARCHITECTURE.md#windows-distribution).
