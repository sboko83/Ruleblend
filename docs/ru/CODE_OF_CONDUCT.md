# Правила поведения

[English version](../../CODE_OF_CONDUCT.md)

## Ожидаемое поведение

Относитесь к участникам уважительно независимо от происхождения, идентичности и опыта. Обсуждайте
техническую проблему, давайте конкретную обратную связь и допускайте обоснованное несогласие.
Уважайте приватность; при обсуждении пользовательских файлов и настроек ассистентов используйте
тестовые примеры.

Недопустимы травля, дискриминационные оскорбления, угрозы, сексуальные домогательства, раскрытие
чужих личных данных без согласия и систематическое нарушение работы обсуждений.

Правила действуют в issue, pull request и других пространствах проекта, а также при публичном
представлении проекта.

## Сообщения и меры

О нарушениях сообщайте приватно на [s.bokonyaev@yandex.ru](mailto:s.bokonyaev@yandex.ru) с темой
`Ruleblend conduct`. Приложите контекст и ссылки; не передавайте посторонние личные данные.
Для уязвимостей действует отдельный порядок в [SECURITY](SECURITY.md).

Владелец рассматривает сообщения, раскрывает личные сведения лишь в объёме, нужном для их
рассмотрения, и может удалить материалы, вынести предупреждение или ограничить участие с учётом
тяжести и повторяемости нарушения. За разъяснением или пересмотром решения можно обратиться
по тому же приватному каналу.
